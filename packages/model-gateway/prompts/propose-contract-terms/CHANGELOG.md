# propose-contract-terms

Each version is a directory (v<n>/) whose prompt.json and schema.json never change once released; a change
is a new version with an entry here. The SHA-256 is the one prompt.json records for its content (the system
prompt, the pinned model identifiers, the token limit, the effort and the schema); a test recomputes it.

## propose-contract-terms/1 (2026-10-16)

- First version. Candidate rate terms from a contract's or exhibit's pages: every field with its page and a quote copied from it, values copied as written for code to read, overlapping terms proposed apart. A second pinned model for contracts the specialist marks ambiguous.
