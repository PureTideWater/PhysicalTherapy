How sources were read. `raw.githubusercontent.com` and the npm registry were reachable and read directly (CHANGELOG.md files, tarballs, `npm view`). `github.com` and `api.github.com` were refused to direct clients (403), so GitHub release pages and issue 8393 were read through a page-fetch tool that returns a summary of the page, not the verbatim text; those lines are marked "(summarised fetch)". ## Most important: @smithy/core 3.38.0 -> 3.39.0 (logger redaction bug)

Issue aws/aws-sdk-js-v3#8393, "Custom loggers receive unredacted data when nested in lists & maps" (open; labels bug, p1, released, potential-regression) (summarised fetch). What leaked: fields marked sensitive in the service model were passed unredacted to the logger when they sit inside a list item or a map value of a command's input or output; the issue's example is the secret values returned by Secrets Manager BatchGetSecretValue. Conditions: only when a custom `logger` is set in a client's config and that logger's `.info()` actually emits the command input/output (the example is `logger: console`); a client with no `logger` is not affected. Top-level sensitive fields, including the credential responses of STS, SSO and Cognito, stayed redacted. Affected: `@smithy/core` >=3.24.0 <3.38.1 (and `@smithy/smithy-client` >=4.5.0 <4.13.0). Fixed in `@smithy/core` 3.38.1, whose changelog entry reads "Redact sensitive fields within list items and map values in schema-based logging"; 3.39.0 contains it. Upstream action: upgrade, and if a custom logger was used with an affected version, review those logs and rotate any credentials or secrets found. Checked on npm: 3.38.0 carries the deprecation, 3.38.1 and 3.39.0 do not. Two things to check locally: (1) whether any SDK client in the repo is constructed with a `logger` (if none, nothing was exposed); (2) the lockfile must resolve 3.39.0 everywhere, because `@aws-sdk/client-*` 3.1164.0 still declares `@smithy/core: ^3.38.0`, a range that admits the deprecated version. Sources: https://github.com/aws/aws-sdk-js-v3/issues/8393 ; https://raw.githubusercontent.com/smithy-lang/smithy-typescript/main/packages/core/CHANGELOG.md ; `npm view @smithy/core@3.38.0 deprecated`.
